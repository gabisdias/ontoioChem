# Ontology version comparison

Comparison order follows the names v2, v3, v4, v6, v8, v9, v10, v11. The OneDrive captures support three groups of last-modified dates (6, 7 and 8 October; year 2026 inferred) but not the order within a day — see [provenance](provenance/README.md). The working copy `ontoiochem.owl` corresponds to v11. This order is not proof of chronology. v5 and v7 were not supplied; files without an explicit version number are outside this chain.

Differences are observed changes, not necessarily improvements. RDF diffs use isomorphic comparison of blank nodes; they do not prove OWL logical equivalence and are not reasoner validation.

The counts were computed on v11 **as originally received**. The annotation translation was applied to every version that contained the line (including every file in the comparison chain), so it adds no difference between them and the counts should be unchanged if the script is re-run; this was not re-run here because `rdflib` was unavailable.

Full lists of added and removed entities and triples per pair are regenerated by `python tools/audit/compare_versions.py` into `build/ontology-diffs/`.

Notable changes:
- **v9 → v10:** `CoordinatesInput`, `CoordinatesOutput` and `hasCoordinatesOutput` appear; the declarations of `Molecule` and `Coordinates` and the property `hasMolecule` disappear. The sets alone do not show that every removal is a rename.
- **v10 → v11:** `inchi`, `inchiKey`, `itemName` and `iupacName` appear; the declaration of the class `Smiles` disappears. The internal comment saying classes were preserved therefore does not fully describe the difference.
- The triple diffs also record changes in domains, relations and annotations beyond the entity lists.
