# Tag explorer

Tkinter application to browse `dictRef` tags across ioChem-BD XML files and annotate them for the ontology mapping. Versions v2, v4, v5 demo and v5 export are kept side by side; see [the audit](../../docs/tag-explorer-audit.md) for what each contains.
